# Sportsbook and hosted connections

The included Rise Sportsbook includes workflows for quote validation, accepted/pending records, canonical debit, authorized reject/cancel and one linked refund. It does not ship a blanket guarantee for real match feeds, finality or open-ended automated result settlement. Do not invent a result for a pending coupon.

ChessBet is a separately hosted private B2B game engine. Open Core includes an iframe/API connector and signed wallet interaction contracts. The partner/operator maintains users, canonical funds, and resulting economic transactions; the hosted game service must not create another spendable wallet authority.

Neither a provider's HTTP success nor a manual result status is proof of final financial settlement without the corresponding approved evidence.
