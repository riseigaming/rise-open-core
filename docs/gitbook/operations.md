# Operations and evidence

Ops Radar is a permission-aware read model over existing canonical finance, internal/external games, Sportsbook, ChessBet, Nova and Global sources.

The evidence vocabulary is intentionally precise:

| Status | Meaning |
| --- | --- |
| `observed` | Recorded event; not automatically a financial effect |
| `applied` | Confirmed canonical transaction and ledger evidence |
| `pending` | Awaiting action, settlement or required proof |
| `protected` | Recognized replay or duplicate claim protection |
| `failed` | Explicit failed/rejected recorded operation |
| `unknown` | Insufficient or inconsistent evidence |

A dashboard row is not a payment executor. Additional analytics and automation may be offered through other product packages; these do not change the authority of canonical financial records.
