# Rise Open Core — Developer Documentation

Rise Open Core is the publicly available, Apache-2.0-licensed developer foundation for a customizable iGaming platform. You can **download, fork, modify and commercially use** the included source code, subject to its license and third-party notices.

The codebase connects a single user/account and canonical wallet, transaction and ledger authority with Global content management, eight internal game variants, built-in Sportsbook workflows, connector contracts and basic operational evidence.

**Product distribution has two tiers:** Rise Open Core (this repository) and a separately commercial Rise Full. Nova Gateway, ChessBet and managed integrations are optional **services**, not a third Rise tier; their private engines are not included in the Open Core source.

Production operators arrange the relevant provider agreements, financial operating controls, market authorizations and deployment acceptance for their own environment.

Start with [Install](installation.md), then [First operator walkthrough](first-admin.md). Existing source and contracts are available in [GitHub](https://github.com/riseigaming/rise-open-core).

For route parameters and examples, use the developer contracts linked from each topic. Read them against the exact revision you are developing.
