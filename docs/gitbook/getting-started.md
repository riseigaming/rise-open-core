## What you receive

An Apache-2.0 source checkout, local installer guide, PHP/Laravel application, CMS Global/admin, game and provider adapter code, canonical finance controls, tests and public documentation.

## Source package and separate services

Private Nova Gateway or hosted ChessBet engines, Rise Full, licensed third-party feeds, real-money processing, production authorization, a provider contract, or an automatic update subscription.

## First rule for AI-assisted development

Keep the model at the interpretation and assistance layer. Permissions, wallet transactions, game outcomes and provider settlement must remain controlled by deterministic server-side contracts and auditable sources. See [repo agent instructions](https://github.com/riseigaming/rise-open-core/blob/main/AGENTS.md).

For a source-backed capability overview, read [Capability Map](https://github.com/riseigaming/rise-open-core/blob/main/docs/CAPABILITY_MAP.md).
