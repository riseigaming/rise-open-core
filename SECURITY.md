# Security policy

For a suspected security vulnerability, use GitHub's private vulnerability reporting
feature if enabled, or contact the repository owner privately through GitHub.
Please do not post credentials, vulnerable customer records or a working exploit in a
public issue. Include affected version, reproduction steps and expected impact.

No production security certification or guaranteed response time is implied.
Do not enable real-money gateway or payout paths without independent provider,
financial, legal and operating acceptance. Keep documented server-side safety guards.
