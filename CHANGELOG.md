# Changelog

## Initial Rise Open Core source snapshot

This initial repository commit contains the canonical Apache-2.0 Open Core
distribution, source manifest, developer documentation, local installation
guide, included game engines, and safety-tested integration boundaries.

Rise Full is a separate commercial distribution. ChessBet, Nova Gateway and
managed services are optional products and services; their hosted private
engines are not part of this repository.

Future source changes will be recorded here as new releases. Source code and
installation guides do not grant production, payment, gaming or provider
authorization.
